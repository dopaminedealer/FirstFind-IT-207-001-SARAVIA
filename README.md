# FirstFind-IT-207-001-SARAVIA

## Command Description
FirstFind combines the filesystem commands of grep and head to search through a file and output a specified pattern and the amount of lines to look through.

The correct invocation of FirstFind is: node ff.js PATTERN FILENAME NUMBER_OF_LINES
